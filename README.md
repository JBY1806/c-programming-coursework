# C Programming Coursework (공학전산응용)

> Undergraduate C programming assignments — functions, pointers, structs, and control flow. Gachon University, Dept. of Electronic Engineering.

## 개요
학부 '공학전산응용' 과목의 C 언어 과제 모음입니다. 함수 분리 설계·포인터·구조체·제어문을 실습했습니다.

| 파일 | 내용 |
|---|---|
| `calculator.c` | 사칙연산 계산기 — 연산별 함수 분리 설계 |
| `rectangle.c` | 2차원 좌표 두 점으로 직사각형 폭·높이·넓이 계산 — 기능별 함수 분리 |
| `sum.c` | 정수 N 입력 합산 — 반복문·함수 |
| `1.c` | 문자열 처리 — 배열·포인터 활용 |
| `0603.c` | 구조체(struct) 실습 — 학생/제품 레코드 관리 |

## 환경
C (GCC/Visual Studio), 원본 과제 파일을 UTF-8로 변환해 수록 (내용 무변경)
